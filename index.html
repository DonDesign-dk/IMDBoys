Firebase er ikke sat op endnu.

Åbn index.html, find const firebaseConfig nær toppen af scriptet, og indsæt jeres egen Firebase-konfiguration derinde (fra Firebase Console → Project settings → Your apps). Gem filen og genindlæs siden.
